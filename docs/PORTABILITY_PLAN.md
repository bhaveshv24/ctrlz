# Portability completion

The product must earn its general-purpose claim through independent examples.

1. Import public GitHub repositories, ZIP snapshots and explicitly allowed local repositories
   into managed snapshots. Preview framework, immutable tests, dependencies and support limits.
2. Provide Python/pytest, Node's native test runner and JavaScript/TypeScript Vitest profiles.
   Resolve declared dependencies inside credential-free setup containers; execute candidate
   tests offline. Never run imported scripts on the host or modify acceptance tests.
3. Make HTTP service integration the default. Project-owned endpoint/operation/predicate
   contracts define monitoring, preconditions and acceptance. CampusPass becomes a demo preset.
4. Remove application-specific concepts from core safety, planning, monitoring and navigation.
5. Verify imports and repairs on independent Python and JavaScript repositories, including a
   real public upstream snapshot with an explicitly disclosed controlled regression.
6. Ship observable receipts and an unsupported-case report instead of claiming arbitrary fixes.

A ten-point score is an aspiration, never an outcome the product can guarantee. Deployment
and publishing remain separately tracked in SUBMISSION_CHECKLIST.md.
