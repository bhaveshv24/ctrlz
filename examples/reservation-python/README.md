# Healthy reservation fixture

A deliberately small local demonstration fixture, not a production repository.
The existing tests pass. Demo Lab can introduce a **disclosed injected regression** in a
separate managed copy by changing the capacity comparison. The original stays unchanged.
No dependencies, external services, credentials or remote repository are required.

Import this directory using Repository repair → Server folder, then open Demo Lab and refresh
targets. Choose the imported Python snapshot and run Disclosed injected regression.
The original tests must pass and the copied baseline must fail before normal repair starts.
Live repair still needs NVIDIA NIM credentials; no model result is simulated.
